# Western Governors University Advanced Java project

## Project Overview
This repository contains a Spring Boot application with Angular frontend that was built as part of a school project. All code written and tested by me are the Dockerfile, and Java files. Parts of the Angular code were modified to fit the new Java code. However this projects focus was not on the Angular parts, but the Java and Docker code.

## Features Implemented
- **Multithreaded Language Translation**: Real-time translation capabilities using concurrent processing
- **Timezone-Based Messaging**: Dynamic message display based on user's local time zone
- **Currency Exchange**: Real-time currency conversion functionality
- **Docker Containerization**: Complete application packaging for cloud deployment

## Technical Requirements
- Java 11 or higher
- Spring Boot Framework
- Angular Frontend
- Docker for containerization
- Cloud deployment capabilities

## Getting Started
1. Clone the repository using Git
2. Import into IntelliJ IDEA (version 2022.3.2 or higher)
3. Ensure all dependencies are resolved
4. Run the application locally to verify functionality

## Deployment
1. Build the Docker image using provided Dockerfile
2. Push to container registry
3. Deploy to cloud environment
4. Configure environment variables as needed
